# Full-Stack Application - Node.js/Express Frontend + Flask Backend

A complete full-stack application with a Node.js/Express frontend and Flask backend, integrated with MongoDB for data persistence.

## Features

- **Frontend**: Express.js server serving static HTML form
- **Backend**: Flask API with MongoDB integration
- **Form Submission**: Dynamic form validation and submission to MongoDB
- **Data Display**: Real-time data fetching and display in table format
- **Docker Support**: Dockerized frontend, backend, and MongoDB
- **Docker Compose**: Orchestrated multi-container setup
- **CORS Enabled**: Cross-origin requests handled properly
